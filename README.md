# data10-02 · APQP Smart Review — 초도품 APQP 제출서류 정합성 검증·승인 검토

협력사 초도품 APQP 서류(Flow Chart · 관리계획서 · PFMEA · 검사기준서 · 외주품 리스트)를 올리면 문서 간 공정·관리항목 정합성을 규칙으로 대조해 누락·불일치·확인 필요 목록과 승인 의견 제안을 내고, APQP 승인 검토 보고서(Excel·인쇄·Word)와 재제출 비교까지 만드는 브라우저 도구

| 과정 | 현장 데이터 디지털화 전문가과정 2차수 (2026) |

> 실제 APQP 서류는 아직 받지 않았습니다. 들어 있는 예시는 **협력사 B · 품번 SMP-2041 · 외주처 가/나 로 지은 가상 데이터**입니다. 회사 자료는 이 리포에 넣지 않습니다.

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data10-02/**

처음 열면 대시보드입니다. **「예시 데이터로 시작」** 을 누르면 가상 검토 건 2개(1차 제출 · 2차 재제출)가 들어가고 1차 제출의 정합성 검토 화면으로 넘어갑니다. 1차 제출에는 결함 5가지를 일부러 심어 두었습니다 — 공정 30 이 PFMEA 에 없음 · 「용접 각장」 특별특성 ◇/◆ 불일치 · PFMEA RPN 140 항목이 관리계획서에 없음 · 출하검사 「외관」 주기 불일치 · 외주 공정 60 도장이 외주품 리스트에 없음(→ 반려 제안). 2차 재제출은 이를 고친 세트입니다(→ 고쳐짐 5 · 남음 1 · 조건부 승인 제안).
실제로 쓸 때는 「서류 업로드」에서 검토 건(협력사·품번)을 만들고 서류 Excel 을 고르면 됩니다. 파일은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다.

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀은 `vendor/` 의 SheetJS, PDF 는 `vendor/pdfjs`).

| 서류 업로드 | 검토 건 만들기·재제출 등록 · Excel·CSV·통합 문서(시트 여러 개)·글자가 든 PDF(시범) · 서류 종류 추정 · 제목 줄 아래 머리행·두 줄 머리·병합 칸 · 열 직접 고르기(같은 양식에 기억) · 정규화 미리보기 · 빈 양식 |
| 정합성 검토 | 적합률·적합·불일치·누락·확인 필요·승인 의견 제안 · 규칙별 결과 · 판정 목록(판정·규칙·근거 서류·찾기) · 근거(서류·행)를 누르면 그 행 보기 · 앞 제출 비교 한 줄 |
| 공정 대조표 | 공정 × 서류(Flow · 관리계획서 · PFMEA · 검사기준서 · 외주 리스트) — 있음·누락·Flow 에 없음·대상 아님, 공정명 다른 칸 표시, 이동·보관 등 대조 제외 공정 |
| 승인 검토 보고서 | 승인 의견 제안(승인/조건부 승인/반려 — 제안일 뿐) · 검토자 결정·의견·보완 요청(지적에서 채우기) · AI 로 보고서 문장(프롬프트 복사 → 답 붙여 넣기, **협력사·외주처·품번은 별칭으로 가림(기본)**, 선택: 설정한 AI 서버로 자동 보내기) · Excel(요약·판정 목록·공정 대조표·재제출 비교·규칙 설정·서류 데이터) · 인쇄/PDF · Word(.doc) |
| 검토 이력 | 품번별 제출 차수·적합률·지적·제안·결정 · 앞 차수와 비교(고쳐짐 · 남음 · 새로 생김) · 지우기 |
| 설정 | 규칙 8개 켜기·끄기·심각도(중대/경미)·기준값(제외 공정, 공정명 닮음, RPN·S, 특별특성 기호 대응표, 검사 공정 낱말, 주기·시료수 비교) · 항목 이름 대조 기준 · 승인 의견 제안 기준 · 별칭 가리기 · AI 연결(OpenAI 호환 주소·모델·본인 키) · DRM·공유 안내 · JSON 백업·되살리기 |

- 로직 테스트: `node test/logic.test.mjs` (의존성 없음, 37개)
- 샘플 파일 다시 만들기: `node scripts/make-samples.js` → `samples/예시_APQP_SMP-2041_1차제출.xlsx`·`2차재제출.xlsx`(다시 읽어 원본과 같은지 확인)·`예시_관리계획서_병합없음.csv` / `python3 scripts/make-sample-pdf.py` → `samples/예시_APQP_SMP-2041_검사기준서_2차.pdf` (reportlab)
- 브라우저 점검(선택): `PLAYWRIGHT_CORE=<playwright-core 경로> node scripts/check-browser.mjs` — 주요 흐름(예시·실제 업로드·PDF·재제출·설정) + 6가지 폭 × 7화면 가로 넘침
